# Extension — Real Estate Transaction

Use with the Case OS core.

Typical workstreams:
- contract / legal
- property due diligence
- mortgage / financing
- ownership / tax
- insurance
- title / settlement
- repair / initial capex
- moving / utilities

Typical gates:
- loan application
- financing / contract-condition deadline
- material DD acceptance
- final lender decision
- settlement
- handover / move-in

Evidence priority should normally favor:
1. signed contract / disclosure / special clauses
2. public registry / government records
3. lender official material
4. title/building records
5. seller-provided documents
6. professional reports
7. counterparty explanations
8. secondary sources

Do not convert this extension into case-specific advice without the actual contract/source evidence.
