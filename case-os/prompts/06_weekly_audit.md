# Case OS Weekly PMO Audit

For each active Full/Dedicated case inspect:

1. duplicate tasks/outcomes
2. P0/P1 without reasonable deadline
3. Critical Path missing mandatory fields
4. DONE without evidence
5. WAITING aging / missing follow-up
6. BLOCKED without unblock condition
7. unresolved items before next Gate
8. missing/expired documents
9. unprocessed material events
10. stale decisions/RAID
11. implemented Change without full cascade
12. next irreversible event still correct
13. Case Health still justified
14. unnecessary registers/automation/noise

Return:
- Health changes
- Critical Path changes
- new/closed exceptions
- decisions required
- next week's top 3
- cleanup/deletion candidates
